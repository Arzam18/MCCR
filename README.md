# MCCR Overview
If Mobile Chess Engine Circuit(MCEC) is focus on tournaments and inspired from CCC and TCEC. Mobile Computer Chess Rating(MCCR) is a on the other hand is focus on ratings of the chess engines for android and inspired from CCRL and CEGT.
